# 数据合同与第一阶段边界

证券主键使用`代码.市场`，避免同代码跨市场冲突。A股导入明确排除ETF/指数，暂不解析扩展市场文件。

| 数据 | 来源 | 单位 / 时点 | 处理 |
|---|---|---|---|
| OHLC | vipdoc/{sh,sz,bj}/lday/*.day | 元；int分价÷100 | 原始不复权 |
| volume | 同上 | 股；bigint | 不随价格复权 |
| amount | 同上 | 元；原文件float32 | 不随价格复权；非逐分精度 |
| category1权息 | T0002/hq_cache/gbbq | 每10股分红、配股价、送转、配股数 | 逐事件仿射复权 |
| category5股本 | 同上 | c1变动前流通、c2前总、c3后流通、c4后总；万股 | 保存事件日之后的股本依据 |
| 基础股本 | base.dbf LTAG/ZGB | 万股；源缓存当前快照 | 不回填快照日之前 |
| 分类/成分 | tdxhy.cfg,incon.dat,spblock.dat | 采集日快照 | 不伪造历史成员关系 |

前复权计算：单次事件`m=(10+送转+配股)/10`，`c=(分红-配股×配股价)/10`，按从新到旧事件累计`A←A/m，B←B-A×c`，最终`Pqfq=A×Praw+B`，四舍五入到分。事件当日不调整当日原始价格。基准日不会超过查询所用末交易日。仅适配普通仿射前复权；用户此前核验值用于样本验收，不能替代全市场回测审计。

对同名数量字段按类别解释：类别1的c3不是流通股本。类别11/12扩缩股尚未支持，不默当普通分红处理。

换手率`100×volume_shares/float_shares`。按日期选最近可用观察值，结果附来源。事件向后延续属于估算；无法证明股本历史完整，不能宣称交易所级精确换手率。自由流通股与已上市流通A股不同。

文件SHA256相同跳过；变化则重读并只upsert不同记录；文件缩短、日期乱序、重复、异常价格、读取过程中变化均拒绝并保留错误。逐文件事务避免一个文件失败导致整批丢失。导入由PostgreSQL advisory lock互斥。

历史筛选的有效日期来自已入库真实交易日期，不以周一到周五替代交易日历。财务、图谱、新闻的严格point-in-time还需后续版本建设。

默认交易日策略：北京时间15:45前不使用当日盘中行；并要求所选日期的证券数量达到最近45个自然日最高单日覆盖数量的80%。这是数据覆盖检查，不是行情完整性保证。显式历史日期可查看低覆盖日期，但结果返回partial与覆盖比例。避免少数股票写入当日记录后，全市场扫描意外只剩几只股票。
