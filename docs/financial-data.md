# 通达信专业财务数据

## 保存与企业差异

源目录为 `D:\tdx\vipdoc\cw`。按季度选取gpcwYYYYMMDD.dat，同期没有DAT时读取ZIP；源文件不修改。每个文件版本保存SHA256、报告期、首次采集时间、字段数量，全部原始float32载荷及原索引序号保存在financial_report。未知FN字段也完整保存，支持按编号读取。历史早期字段数量不同，不能假定都含584个字段。

分三层处理：

|层|内容|
|---|---|
|原始|股票、报告期、文件版本、FN编号和值、原载荷、公告日、采集及核验时间|
|标准指标|明确字典和单位的公共科目，统一金额为元，保留来源FN编号和映射版本|
|企业展示|根据当前行业快照识别普通企业、银行、证券、保险、其他金融企业；保留专用字段适用性|

企业类型只用于当前展示模板，不冒充历史行业归属，不依据字段为零判断适用性。不把银行不存在的存货等科目补零，也不把“其中营业收入”自动代替“营业总收入”。当前已核对48个字段，其他字段名称和单位保持未确认。

公共映射：FN502营业总收入（万元×10000）；FN96归母净利润、FN271归母权益、FN40总资产、FN63负债、FN72权益合计、FN95净利润、FN107经营现金流（这些字段原单位元）。利润/现金流按年初累计口径。FN314财报公告日期单独解析。原始float32精度保留，因此展示数值可能有尾数。

字段依据：[通达信官方专业财务字段说明](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)。

## 冲突和可见时间

同文件、同代码存在多条记录时：逐字段一致则都保存，计算按一个报告期使用；任意字段不同，整份该报告的全部候选记录标为pending_conflict、standard清空，禁止参与估值和选股指标。即使只冲突股利支付率，也不会采用其他一致科目。必须经用户逐项确认才可后续处理；当前没有自动解决冲突的入口。

本次88组重复报告：55组一致、33组冲突，涉及36个字段，隔离72条源记录。清单见 [待确认报告](financial-conflicts-review.md)，精确候选值保留在同名JSON。raw payload不删除，不按第一条、最后一条或金额大小选择。

财务使用条件：报告期和公告日期不晚于筛选日，且文件已被系统采集、报告已核验。采集/核验时间必须早于筛选日次日北京时间零点，当前仅支持日末研究，不承诺盘中时间还原。历史修订保存新版本，历史查询选择当时已经采集的版本；未来采集版本不回填过去。缺公告日不参与历史计算。

2026-10-16首次采集的数据不能填入2026-10-14任务。旧下载包不等于首次披露原版，不补造采集前历史财务指标。

## 选股指标与保存

- 市值：筛选日或最近7个自然日内的不复权收盘价×当日已可见总股本。返回实际price_date、股本来源和生效日；技术选股仍为前复权。A/H多市场公司目前是A股价格乘数据库总股本的研究口径，未分别估算H股市值。
- PE：市值÷最近可见年报归母净利润，保留旧项目公式，非TTM；PB：市值÷最新归母权益。非正分母返回不适用。
- 营收/利润同比：最新报告与上年同报告期相比，分母使用上年绝对值，返回比率（0.10=10%）。上期利润近零、本期为正时利润增长返回字符串inf，PEG不适用，沿用旧规则。
- PEG类指标：PE÷（利润同比×100），只在正且有限的增长率下计算；PE<30、PEG<1、增长为正、最新及最近3份年报净利为正沿用旧规则。缺报告或被隔离时返回空值及原因，不替用户作否定判断。

技术结果仍在multi_screen_run/multi_screen_item，不改已保存信号；财务查询附加结果按symbol/as_of/输入签名保存在financial_metric_cache，行情、股本、财务版本或核验变化使旧缓存失效。原始报告和指标缓存分开保存，技术条件不引用基本面结果。

## 更新与查询

通达信更新财务包与下载日K是两件事。客户端更新专业财务包后，运行：

```powershell
.\.venv\Scripts\python.exe -m quant.cli import-financials
```

已入库相同文件哈希跳过；变化保留新旧版本；文件正在写入、截断、记录数减少会拒绝该文件并保留数据库版本。整次任务逐文件提交，错误记录在financial_import_run，不伪装全部成功；同一时间只运行一个财务导入任务。本阶段网页行情同步按钮不自动代替财务包更新。

接口：

- GET /api/financials/status：覆盖、导入状态、未覆盖证券及隔离源记录数。
- GET /api/financials/300138.SZ?fields=FN96,FN502,FN271：当前下载版报告、模板、指定原始字段及单位。该原始查看接口不宣称历史当时可见。
- GET /api/fundamentals/300138.SZ?as_of=2026-10-16：严格采集可见口径的指标、每字段状态和来源报告。
- MCP新增financial_data_status、financial_reports、stock_fundamentals；已有multi_screen_status附带指标。
