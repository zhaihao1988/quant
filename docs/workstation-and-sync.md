# 盘后看盘与可靠同步

## 网页同步

数据总览逐股展示数据库实际末日期、通达信文件末日期、本地条数与同步状态。可搜索、筛选、分页，基础资料和权息的文件更新时间单独显示。

日常操作：先完成通达信下载，网页“重新对比源文件”，再“同步通达信数据”；也可直接同步，由后台再次判断。重复点击复用同一任务。

- 默认增量核对实际数据库末日期、文件大小、修改标记与最后一个块；未变化文件跳过。
- 文件变化时检查完整SHA256与每256条记录的指纹，定位最早变化块；从该处与数据库末尾重叠20条中更早的位置解析。较早历史修订自动回溯。
- 数据库末日期落后时，即使源文件未变化也补齐，不仅依赖导入清单。
- “完整文件哈希校验”即使修改标记相同也检查所有源文件指纹，适合周期性检查较早修订；不是数据库逐值审计。
- 截断、乱序、导入期间继续变化的文件拒绝或逐文件回滚，其他证券继续。4个工作线程复用连接，每个文件独立事务。
- 失败项逐股保存并可重试；无进程持锁的旧任务可恢复为中断状态，再次同步可续传。
- 同步后自动刷新对比；原有17只缺文件证券不补造数据。

对比表是扫描时快照；“已对齐”不表示源文件永不变化。本轮只处理沪深北A股日线及已有基础资料/权息，不扫描或导入vipdoc/ds扩展行情。

## 看盘图

本地内置Apache ECharts 6.0.0，无运行时CDN请求。采用红涨绿跌、阳线空心、阴线实心。三个网格共用时间轴、十字线和缩放：

1. K线与MA，默认5/10/20/60；支持最多8条、周期1—500。
2. 成交量柱与量MA5/10；图单位手，表格万股，数据库股。
3. MACD默认12/26/9：DIF=EMA(CLOSE,12)-EMA(CLOSE,26)，DEA=EMA(DIF,9)，柱=2×(DIF-DEA)。参数可改。

默认加载全部历史，初始视窗最近120根，可拖动滑块、滚轮缩放、显示全部。起止日期、加载范围和明细分页继续保留；明细每页50条。

## 周月聚合

参考旧项目data_processing/aggregators.py的W-FRI周、自然月及最后动态周期思路，改为纯Python查询时聚合，不复制旧ORM和周月落库流程。

先按统一基准复权日线，再聚合周月：首开、末收、最高/最低极值，量额求和。周月换手率按每日估算值累加；任一天缺分母则整期留空。不补停牌日，K线日期为最后实际成交日。

周月MA/MACD在聚合后重算，使用截至查询日的完整前序历史预热；显示区间变化不重置EMA。EMA以首条可用收盘价为种子，MA不足完整窗口留空。采用常用通达信公式，尚未逐值对照客户端自定义参数及初始化实现。

未结束周/月和显式盘中日线标记“周期未结束”。周月结束判断采用日历周五/月末，尚无完整休市日历，节假日末周期保守标记。长期停牌股票依据查询截止日判断周期结束，不以最后成交日代替截止日。
