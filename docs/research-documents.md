# 调研问答资料库

## 使用

- 股票资料库新增“调研问答 · 近一年”，可启动全部股票更新、暂停、继续和重试失败项。采集范围来自现有A股清单（沪深京），以公告发布时间、上海时区筛选最近一个自然年。
- 多策略选股点击股票后，在个股详情点“调研问答 ↓”，查看公告和问题；最新公告默认展开，其他公告折叠。问题展开显示原文回答，支持查看逐页全文、打开数据库留存的原始PDF和巨潮来源页。
- 首次任务覆盖5594只股票，优先晨光生物及最近选股批次命中股票。采集进程独立于网页，关闭网页不影响任务。
- 更新为手动触发，不与技术选股强制串行绑定，不改原7个策略。增量查询公告ID去重，当前解析版本已成功的文件不重复调用模型；暂停后在当前文件完成处保存并恢复。

## 来源与模型

直接读取巨潮公开股票映射、投资者关系公告列表和官方PDF附件，不引入旧AKShare或旧项目ORM。

硅基流动 `Qwen/Qwen3-8B`，关闭思考、JSON输出。优先按编号和原文标记分割候选问答，模型逐条校验并提取原文主题词、机构名称；模型必须完整分类所有候选。其他格式尝试按原文行号定位。答案由程序从原文复制，禁止用模型生成的总结替换。

保留原始PDF和逐页文字；仅去掉页首/尾与页码相同的孤立页码作解析。分段优先沿问题边界，保留来源页范围。模型不完整、越界、漏问题或不符合原文校验时，文件标为失败并保留原文和未核验输出，供重试。扫描件标为待OCR，本次不接入OCR。规则与模型并不能保证所有文档完全正确，保留原文供核对。

Key通过私有 `.env` 的 `QUANT_SILICONFLOW_API_KEY` 配置，不进入版本库和前端。数据库和业务日志不记录tokens或费用统计。

## 存储

新增迁移014：

- `research_document`：来源公告ID、标题、完整发布时间、来源链接、PDF链接、首次/最近发现时间。
- `research_security`：公告与股票多对多关联，同一公告不重复存。
- `research_revision`：PDF原始字节、SHA256、逐页文字、解析版本、模型、问答/主题/机构JSON、状态、错误、采集和解析时间。
- `research_job` / `research_item`：批次窗口和逐股进度，支持断点继续与失败重试。

PDF直接存PostgreSQL bytea，随现有数据库备份一同备份，不另留必须同步的文件目录。解析版本升级保留旧版本，页面读取最新版本。

后台2线程，来源请求间隔约1.2秒。网络与暂时服务错误有限重试；权限/来源连续受限暂停，禁止把来源失败标作“没有调研”。全局任务锁与公告锁避免并发重复，心跳中断可恢复。无公开记录、无问答、扫描件、解析失败分别显示。
